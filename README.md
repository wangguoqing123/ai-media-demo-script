# 商单样片脚本助手

为小红书AI自媒体学员写软件教程、效果展示与软件测评的样片脚本。输出干净口播稿和对应画面；默认以工具A、工具B呈现产品。当前版本：v0.1.3（公开学习版）。

内置6篇真实案例的封面、来源链接、学习摘要与写作分析，以及口播风格说明和改稿对照。无需老师的工作台、Get笔记、TikHub或小红书登录；本Skill只写脚本，不自动生成素材、剪辑或发布。

## 安装

打开Codex，把下面整段发给它：

~~~text
请使用 $skill-installer 安装「商单样片脚本助手」：
https://github.com/wangguoqing123/ai-media-demo-script

Skill在仓库根目录，路径是“.”，安装名是 ai-media-demo-script。
如已安装旧版，先备份，只更新这个Skill。
完整保留 references、案例封面和 agents，不修改其他Skill和账号资料。
安装后检查版本为 v0.1.3，6篇案例及6张封面齐全。
~~~

安装完成后，下一条消息即可调用；暂时没有识别到时，重启Codex再试。[OpenAI官方Skill说明](https://learn.chatgpt.com/docs/build-skills)

## 使用

把自己的操作录屏、成果截图或文字记录发给Codex，再发：

~~~text
使用 $ai-media-demo-script，帮我写一条商单样片脚本。
内容方向：[AI办公 / AI视频 / Vibe Coding]
想展示的任务或效果：[填写]
我实际做了什么：[填写，也可以附录屏]
实际得到的结果：[填写]
后来改了哪里：[有就填，没有就删掉]
参考样片：[选填，可用内置案例或我提供的文案]

产品用工具A代称，输出口播稿和对应画面。
~~~

不必先写专业需求书。最少说明“做了什么、结果怎样、有没有修改”；测评补充输入与条件。只有结果可以先写成果展示；需要实操教程时补制作记录。

还没做过实操，也可以说“先帮我定开头和取材清单”。它会先给可拍方案，需要记录的中段等实际操作后再写，不编亲测、耗时或费用。需要改稿时直接指出“不够吸引人”“这句像说明书”，并补上想参考的说法。

## 案例与边界

- [6篇案例索引](references/case-index.md)：保留作者、原链接与封面，区分合作记录和内容形式参考。
- [写作分析](references/case-patterns.md)：怎样从具体效果、任务或选择问题进入，而不是照念操作步骤。
- [风格与改稿对照](references/style-guide.md)：演示、任务比较与创意故事分别处理，避免写成同一腔调。

案例文字是学习摘要，不是完整转写；部分案例仅有标题、封面和既有摘要，不补造其操作与口播。第三方案例与封面保留原作者归属，只用于理解与学习，不作为学员自己的作品或素材，也不代表仓库授予第三方内容的再利用许可。

产品代号不是通过审核或避免限流的保证，真实合作保留应有披露。此版本已检查结构与安装流程；脚本质量仍需结合自己的真实材料试写和修改。
